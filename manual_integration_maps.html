Integration Maps

The Integrations tab provides a visual management hub detailing all third-party service connections, payment gateways, messaging services, and external APIs connected to your platform architecture.

Key UI Components

  • Integrations Sidebar: Itemizes all 18 configured integration services (such as Stripe, Razorpay, Google Maps API, Mapbox, Twilio, SendGrid, Firebase Cloud Messaging, and AWS S3) with search and quick-navigation controls.
  • Integration Cards Grid: Interactive tiles displaying specific service configurations:
    • Service Details & Type: Name, category (e.g., PAYMENT_GATEWAY, SMS, FILE_STORAGE, ANALYTICS), and status tag (e.g., REQUIRED or OPTIONAL).
    • Capabilities & Description: Highlights service functions such as tokenization, webhooks, address autocomplete, or infrastructure monitoring.
    • Used in Flows: Direct links to the specific business processes using the integration (e.g., flow-payment-processing, flow-delivery-assignment, flow-registration).
  • Canvas Toolbar: Top-right controls to toggle views between Cards and Graph mode, alongside a Phases (Roadmap) filter.
