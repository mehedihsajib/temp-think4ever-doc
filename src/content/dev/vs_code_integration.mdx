# Connect your project to VS Code (Visual Studio Code)

![VS Code Integration](/images/dev-doc/vscode-1.png)

To connect your project to **VS Code:**

1. Click the **VS Code** button (highlighted in the
 top-right corner).
2. VS Code Integration popup will be prompted.

![VS Code Integration](/images/dev-doc/vscode-2.png)

3. Ensure the VS Code extension is installed on your browser. If
 not, click the **Download.vsix** button then
 install.
4. Once installed, click on the extension icon in the sidebar,
 then select **Think4Ever** icon.
5. Click the ... **(More Actions)** icon at the top
 of the Extensions pane.
6. **Click Install** from VSIX

![VS Code Integration](/images/dev-doc/vscode-3.png)

7. Choose your .vsix file from the file explorer to complete the
 installation.
8. Once opened, your project files will appear in the Explorer
 panel on the left side.

![VS Code Integration](/images/dev-doc/vscode-4.png)

## Troubleshooting: If VS Code does not open automatically

Try these:

- Allow pop-ups in your browser
- Refresh the page and click the button again
- Check if your browser blocked the redirect

## Optional: Open Terminal in VS Code

Inside VS Code:

- Go to **Terminal → New Terminal**
- Or press:
 
**Ctrl +** ` (Windows)
**Cmd +** ` (Mac)
