# Issues

By clicking 'Issues' button you can open the issue popup from
 where you can create and track issues.

![Goto Issue](/images/dev-doc/14-goto-issue.png)

From this issue tab you can create new issues or track existing
 issues. How many open issues are there in total, how many are
 closed and total issues are displayed in the header.

![Issues](/images/dev-doc/15-issue-list.png)
