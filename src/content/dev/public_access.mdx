# Public Access

Public access is the place where you will make your project
 publicly accessible using a public URL.

![Public Access](/images/dev-doc/18-goto-public-access.png)

When you will check the "Enable" button, you will be able to
 access your project publicly with that provided URL.

![Public Access](/images/dev-doc/19-enable-public-access.png)
