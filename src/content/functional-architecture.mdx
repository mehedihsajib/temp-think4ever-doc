# Functional Architecture

The **Functional Architecture** screen provides an
 interactive, visual map displaying all concept screens, system
 modules, and user flows across the platform.

![Functional Architecture Interactive Visual Map](/images/portal/functional-architecture/functional-architecture-1.png)

- **Visual Mapping Canvas:** Groups application
 screens into functional modules (e.g.,
 *Customer Shopping, Account & Auth, Rider App, Store
 Partner, Admin Platform, Expense Management* ).
- **Canvas Controls:** Top-right toolbar allows
 zoom adjustments (zoom in/out, percentage indicator),
 full-screen expansion, reset view, and a
 **Rebuild** option to regenerate the architecture
 layout.
