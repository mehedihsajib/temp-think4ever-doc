# Codex

Codex configures MCP servers using a local configuration file. For a remote HTTP server like
 Think4Ever, Codex utilizes
 the `mcp-remote` bridge utility to translate the HTTP endpoint into its local
 transport
 protocol.

![Codex](/images/mcp/mcp-codex.png)

### Technical Integration

Follow these steps to add the Think4Ever MCP server to your local Codex environment.

### Codex (OpenAI CLI)

Codex configures MCP servers in `~/.codex/config.toml.` For a remote HTTP server,
 use
 the mcp-remote bridge (it turns the
 HTTP endpoint into the local transport Codex speaks).

### Step 1

Add this block to `~/.codex/config.toml` :

```toml
[mcp_servers.Think4Ever]
command = "npx"
args = [
  "-y", "mcp-remote",
  "https://cell-ssm-use1-0005.us.portal.think4ever.com/mcp",
  "--header", "Authorization: Bearer tf_71b84ebb8284f86491f24b85311a55dfd2b0c9e74c678c7e"
]
```

### Step 2

Requires Node.js (for `npx` ). Restart Codex; the `Think4Ever` tools
 become available to the agent.

### Step 3

Verify inside a Codex session — ask it to list its available tools, or just give it a
 think4ever-touching instruction and watch the tool calls.

### Tips

Codex reads `AGENTS.md` for standing instructions — add a line like
 “*Specs and tasks live in Think4Ever(MCP server Think4Ever); read the
 active concept before structural changes.* ” so every session starts
 anchored.
