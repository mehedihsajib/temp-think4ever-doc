# Concept Summary

The **Concept Summary** tab provides a high-level
 system architecture canvas that visualizes top-tier
 applications, microservices, backend dependencies, and
 communication channels across the platform.

![Concept Summary High-Level System Architecture Canvas](/images/portal/concept-summary/concept-summary-1.png)

### Key UI Components

- **Architecture Sidebar:** Lists all 23 high-level architectural blocks (such as *Customer Mobile App, Rider App, Store Partner Portal, Admin Ops Console, API Gateway, Auth Service,* and *Catalog Service*) with object counts and search capability.
- **System Architecture Canvas:** Interactive diagram displaying system boundaries and infrastructure connections:
  - **Frontend & Client Apps:** Top-level cards for client-facing channels (*Customer Mobile App, Rider App, Store Partner Portal, Admin Ops Console*).
  - **API Gateway & Core Services:** Central hub routing requests to dedicated backend microservices (*Auth Service, Catalog Service, Order Service, Payment Service*).
  - **Infrastructure & Messaging Layer:** Nodes representing event brokers and databases (e.g., *RabbitMQ Event Bus, Redis*).
- **Canvas Toolbar:** Top-right controls including layout view selection (*Hierarchical* dropdown), **Fit** (re-center architectural topology), and a **Phases (Roadmap)** selector.
