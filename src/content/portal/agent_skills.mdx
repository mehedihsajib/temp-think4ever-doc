# Agent Skills

The Agent Skills page is where your company writes standing instructions once and has them applied automatically across think4ever. Instead of repeating the same rules in every chat or every project, you record them as skills. Each skill is added on top of the normal task instructions the AI receives, so agents and builders follow your company standards by default.

Skills can be targeted by agent, by concept layer (for example UI Screens or Data Structure), or by kind of work. Once saved, a skill applies to every project and every team member in your company.

### Key facts

- Skills are applied automatically to every project and every team member.
- Each skill can hold up to 12,000 characters.
- Only company administrators can see and edit this page.
- A skill never overrides an explicit request made in a chat. The agent follows the request and tells you which company rule it set aside.

## 3. How skills are applied

A skill is appended to the AI instructions of the matching work. The scope you choose decides when the skill is used.

| Skill scope | When it is applied |
| :--- | :--- |
| Every agent & builder | With every call, for all agents and builders. |
| Concept builder (all layers) | Whenever a concept is built or changed, regardless of layer. |
| A concept layer (e.g. UI Screens, Business Flows) | Only when that specific layer is built or changed. |
| An individual agent | With that agent’s tasks only. |

<Callout type="tip" title="Tip">
Put rules that always apply (tone, naming conventions, language) in Every agent & builder, and keep layer-specific rules in the matching layer skill.
</Callout>

## 4. Step-by-step instructions

### 4.1 Open the Agent Skills page

1. Sign in to think4ever. You land on the Your Projects screen.
2. Click the Agent Skills tab in the tab bar (Figure 2).
3. The page opens with the skill list on the left and an empty editor area on the right.

![Figure 2. The Agent Skills tab](/images/portal/agent-skills/figure-2.png)

<p className="text-center text-sm text-slate-500 dark:text-neutral-400 mt-1.5 mb-6">Figure 2. The Agent Skills tab</p>

<Callout type="note" title="Note">
If you do not see the Agent Skills tab, your account is probably not a company administrator. Ask an administrator for access.
</Callout>

### 4.2 Find a skill

1. Look at the skill list on the left. Skills are grouped under General, Concept Builder, Concept Layers and Design & Documents.
2. To jump to a skill, type part of its name in the Find a skill box (marker 1, Figure 3). The list narrows as you type.
3. Scroll the list to see further groups below Design & Documents.

![Figure 3. The skill list and its groups](/images/portal/agent-skills/figure-3.png)

<p className="text-center text-sm text-slate-500 dark:text-neutral-400 mt-1.5 mb-6">Figure 3. The skill list and its groups</p>

| # | Element | Description |
| :--- | :--- | :--- |
| 1 | Find a skill | Search box for filtering skills by name. |
| 2 | General | Contains Every agent & builder, used with every call. |
| 3 | Concept Builder | Contains Concept builder (all layers). |
| 4 | Concept Layers | One skill per layer: UI Screens, Business Flows, Data Structure, Roles & Permissions, Integrations, Business Rules, Concept Summary (Architecture), API Endpoints, State & Lifecycle, Events & Jobs, Environment & Config. |
| 5 | EMPTY badge | No instructions have been written for this skill yet. |
| 6 | Design & Documents | Further group of skills below the concept layers. |

### 4.3 Write or change a skill

1. Click the skill you want in the list, for example UI Screens.
2. The editor area on the right replaces the prompt "Pick a skill on the left to write or change its instructions."
3. Type or paste your instructions in plain language, written as direct rules.
4. Keep the text within 12,000 characters.
5. Save your changes using the on-screen save control in the editor.
6. Check the skill in the list. Once it contains instructions, its EMPTY badge no longer applies.

<Callout type="important" title="Remember">
Skills do not override an explicit request made in a chat. The agent follows the request and states which company rule it set aside.
</Callout>

### 4.4 Export and import skills

- **Export:** click Export at the top right (marker 1, Figure 4) and save the downloaded file as a backup.
- **Import:** click Import (marker 2), choose a previously exported skills file, then review the list to confirm the instructions loaded.

![Figure 4. Export and Import buttons](/images/portal/agent-skills/figure-4.png)

<p className="text-center text-sm text-slate-500 dark:text-neutral-400 mt-1.5 mb-6">Figure 4. Export and Import buttons</p>

<Callout type="warning" title="Caution">
Importing may replace instructions that already exist in a skill. Export your current skills first.
</Callout>

## 6. Writing effective skills

- Be specific. "Use sentence case for all button labels" works better than "Make the UI consistent."
- Write one rule per line so instructions are easy to scan and update.
- Put universal rules in Every agent & builder and layer rules in the matching layer.
- Avoid contradictions between skills.
- Stay well below the 12,000 character limit.
- Review skills regularly and remove out-of-date instructions.

## 7. Troubleshooting and FAQ

| Question | Answer |
| :--- | :--- |
| I cannot see the Agent Skills tab. | Only company administrators can see and edit this page. Ask an administrator for access. |
| Why does the agent ignore my skill? | A skill never overrides an explicit request in a chat. Also check the skill is in the right scope. |
| Do skills apply to existing projects? | Yes. Skills apply to every project and every team member. |
| What does EMPTY mean? | No instructions have been saved for that skill yet. The editor shows NOT SET for the same reason. |
| What does the Enabled switch do? | It turns the skill on or off. Leave it on for the skill to be applied. |
| I need a starting point. | Click Insert an example in the editor, or Load from a .md / .txt file. |
| Is there a size limit? | Yes. Up to 12,000 characters per skill. |
| How do I back up my skills? | Use Export at the top right of the page. |
