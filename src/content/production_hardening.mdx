# Production Hardening

The Production Hardening automatically evaluates your codebase against a
 comprehensive production-readiness checklist. Reviewer agents scan your project structure and source files
 in real time, allowing you to monitor progress live or safely navigate away while the review runs in the
 background.

- **Category:** Code →Production Ready
- **Best For:** Teams preparing to deploy applications to production or conducting security
 and compliance audits.
- **Function:** Imports your codebase and maps the system architecture, then deploys
 reviewer agents to audit against key production readiness domains (including security, configuration,
 reliability, data management, and observability).
- **Action:** Click Harden a project →to proceed.

![Create Project](/images/create-project/product-hardening-1.png)

The Production Hardening screen allows you to import your codebase into the
 platform. Once imported, the system maps your architecture and automatically executes a
 **production-readiness review** .

![Create Project](/images/create-project/product-hardening-2.png)

## Import Options

Select one of the three available methods to bring in your source code:

- **Upload a ZIP (Local Project):** Upload an archived file directly from your local
 machine without authenticating or connecting a source-control account. Click Choose a file → to select a
 compressed .zip archive.

![Create Project](/images/create-project/ph-upload-as-zip.png)

- **Public GitHub URL (Public Repository):** Paste a link to any public repository, and the
 system will download a snapshot of your designated branch. Click Import from GitHub → to proceed.

![Create Project](/images/create-project/ph-github-url.png)

- **Connect a repository (Version Control):** Authorize private or public repositories
 using account credentials. Click Connect → to link repositories hosted on GitHub, GitLab, Bitbucket,
 Git, or SVN.

![Create Project](/images/create-project/ph-connect-git-repo.png)

## Step by step process

- **Step 1:** Select your preferred import method and complete the upload or authorization
 prompt.

![Create Project](/images/create-project/step-1.png)

- **Step 2:** Upload the file to be imported.

![Create Project](/images/create-project/step-2.png)

- **Step 3:** Analysis of the codebase will begin

![Create Project](/images/create-project/step-3.png)

- **Step 4:** System will build the concept from the uploaded codebase

![Create Project](/images/create-project/step-4.png)

- **Step 5:** Once codebase concept is built, the production hardening process will start
 by reviewing your existing codebase.

![Create Project](/images/create-project/step-5.png)

- **Step 6:** View the overall readiness summary, showing the exact percentage of
 completion and passed checks across all categories.

![Create Project](/images/create-project/step-6.png)

- **Step 7:** The system will give you the option to Fix Findings, tap the button to start
 fixing the issues. Or you can also click on Run again button to re-run the analysis of your codebase.

![Create Project](/images/create-project/step-7.png)

- **Step 8:** Click on Fix Findings - then choose which agent to use.

![Create Project](/images/create-project/step-8.png)

- **Step 9:** Wait for the system to fix each issues one by one.

![Create Project](/images/create-project/step-9.png)

- **Step 10:** As the system addresses each issue, it will prompt proposed fixes or planned
 changes; you need to confirm the changes before the system can proceed further.

![Create Project](/images/create-project/step-10.png)

Once all the fixes are done, you can continue generating UI screens and bulding the
 app.
