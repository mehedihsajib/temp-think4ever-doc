## Troubleshooting and FAQ

| Question | Answer |
| :--- | :--- |
| **Why can't I see the Lock Design option?** | You must be a Project Owner or Company Administrator to access the lock controls. |
| **Why did the modal tell me someone else is editing?** | If another team member has unsaved active edits, resolve those changes before locking. |
| **I locked it by mistake. Can I undo it?** | Yes. Simply choose Unlock Design from the project menu if you have appropriate permissions. |
| **Can I still use the API or MCP when locked?** | Yes. Read operations and dev tools continue to function normally. |
| **Does locking stop developers from coding?** | No. Developers can build and edit code in Developer Mode or via connected IDEs over MCP. |
