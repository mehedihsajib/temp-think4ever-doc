Create a New Project

The New Project screen allows users to describe the application, platform, or solution they want to build. Simply enter a business idea, project requirements, or technical specifications in the description field.

The platform analyzes the provided information and automatically determines the most suitable project setup, including project naming, recommended development approach, and initial project structure.

Users may also specify existing assets such as source code, a Git repository, preferred technologies, or implementation requirements. Based on the provided input, the system guides users through the appropriate project creation workflow.

After entering the project details, click Continue to proceed with project generation and setup.

How to Create a New Project

1. In the Dashboard, click on Create a New Project button

2. There are two ways to create a project:

  1. Analyze Existing Code
  2. Design from intent

Option 1: Analyze existing code (Import Existing Code or Project)

Purpose: Designed to parse an existing codebase and automatically turn a project into a visual, reviewable map of the system.

Status: Marked as RECOMMENDED for users starting with an active project or codebase.

  • Core Focus: Reverse-engineering existing codebases into clear visual documentation.
  • How It Works: Scans repository source files, dependencies, and API structures to auto-generate system flowcharts, dependency graphs, and architectural overviews.
  • Best Used For: Onboarding onto unfamiliar codebases, auditing legacy applications, mapping technical debt, or verifying how a live system operates before making modifications.

Option 2: Design from intent (Build the app from scratch)

This guide walks you through creating a complete application blueprint—from defining high-level goals to generating system requirements and UI concepts—using Think4ever.

Step 1: Initiate System Design

  1. From the Think4ever dashboard/home page, click on Create a New Project button.
  2. Click on the Design from Intent - button to start creating your app from scratch.

Step 2: Define the Application Objective

  1. On the What should this application accomplish? screen, enter your main Business objective in the text area.
    • Example: "Customers can request refunds, managers can review exceptions, and every decision remains visible to the customer."
  2. (Optional) Click Attach files or Import from Jira & other tools to provide context such as specs or mockups.
  3. (Alternative) Select a pre-made template under OR START FROM A READY-MADE SOLUTION DESIGN (e.g., Creator Fan Platform, Class Scheduling System).
  4. Click Continue.

Step 3: Answer Concept Key Questions

A modal window titled Key Questions will prompt you to shape the initial concept:

  1. Select target user roles (e.g., Writers who create & sell, Readers who browse & buy, or Both).
  2. Check allowable features and content items (e.g., Cover image, Tags/categories, Pricing).
  3. Choose platform configuration rules (e.g., platform cut percentage).
  4. Click Submit.

Step 4: Requirements Analysis & Questionnaire

  1. Think4ever will generate a Requirements Analysis summary covering:
    • Current Requirements Overview
    • User Roles
    • Key Features & Business Rules
    • Integrations
  2. Work through the follow-up clarification questions. For multiple-choice or edge-case questions (e.g., handling post-publishing updates), you can:
    • Select a specific rule option.
    • Select Let AI decide to let the system determine the standard approach.
  3. Click Submit Answers. The platform will process your input in real time.

Step 5: Review & Approve Requirements

  1. Review the generated structured requirements under Review & approve your requirements.
  2. Toggle checkboxes to include or exclude specific Overview, Goals, and system behaviors.
  3. Once satisfied, click Approve & Build.

Step 6: Automated Concept Build

  1. The platform processes all requirements and generates systemic diagrams, concept blocks, and logic flows automatically.
  2. Wait for the processing pop-up ("Building diagram from analyzed requirements...") to finish.

Step 7: Explore the Concept Blueprint & Next Steps

  1. Upon completion, a Concept Ready modal will display a summary of generated assets (e.g., Concept blocks, Business flows, Roles & permissions, Integrations mapping, Data objects, Business rules).
  2. Click Start UI screens creation or close the dialog.
  3. You can now explore the visual canvas, review roles/permissions, check data objects, or toggle into Dev Mode to begin UI creation and hands-on coding.
