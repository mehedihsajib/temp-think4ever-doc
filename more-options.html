More Options

The More dropdown menu in the secondary navigation bar houses technical artifacts, database structures, integration specs, and backend runtime configurations.

Submenus & Descriptions

  • Concept Summary: Provides an aggregated overview of higher-level system components, architectural groupings, and module summaries.
  • Data Objects: Displays database entity definitions, schema structures, field attributes, and data relationships.
  • Integration Maps: Outlines third-party service connections, external webhooks, and system-to-system data exchange pipelines.
  • API Endpoints: Details REST/GraphQL API paths, request/response payload schemas, authentication methods, and endpoint definitions.
  • State & Lifecycle: Documents state transitions, life-cycle models, and status updates across primary system entities.
  • Events & Jobs: Manages background tasks, scheduled cron jobs, event-driven triggers, and asynchronous worker queues.
  • Environment & Config: Defines workspace variables, feature flags, deployment environments, and global application configurations.
