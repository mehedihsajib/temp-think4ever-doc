API Doc Generator

The API Doc Generator agent parses source code files to automatically generate structured API reference documentation and usage examples.

Core Mechanics

  • Endpoint Scoping: Audits selected route, controller, or request handler files across your project directory, pre-selecting all files by default for a complete API map.
  • Documentation Planning: Generates a preliminary structural blueprint of the endpoints to be documented for confirmation before running the parser.
  • Deep File Parsing: Inspects each file to extract active endpoints, HTTP methods, URI parameters, request bodies, and expected status responses.
  • Structured Reference Output: Publishes an organized, interactive API reference manual complete with request/response schema examples.

Step by Step Guide:

Step 1: Select Your API Source Files

Review your project folder structure. Select the relevant route files, controllers, or endpoint handlers that define your application's entry points. Leave all options selected by default to ensure no endpoints are missed.

Step 2: Approve the Documentation Plan

Review the quick summary plan generated by the agent. This layout verifies which modules and routing files will be indexed. Confirm the plan to start the extraction process.

Step 3: Run the Schema Extraction Engine

Allow the generator to index your code. The engine reads through your code handlers, identifying the exact parameter types, validation rules, query strings, and payload signatures.

Step 4: Utilize the Structured Reference

Access the newly compiled documentation. You can now use the structured reference tables and boilerplate payload examples to update integration setups, share with frontend developers, or export to external API management platforms.
